# 定量建模训练场 · 教练入口

课程仓库位于 vault 的 `10.建模课/`（本技能即其 `skills/modeling-coach/`）。
课程本体 = `MISSION.md` + `docs/` + `lessons/` + `records/` + `progress.md`。

## 开工前（每次必做）

1. 读 `10.建模课/MISSION.md`、`progress.md`、`docs/01-教学协议.md`、`docs/00-课表.md`
2. 读 `records/` 最近 2 条学习记录（确定最近发展区）
3. 确定今天这节课：用户指定优先；否则 = progress.md 标记的"下一课"
4. 读目标课 `lessons/<课>/README.md`（L1 另读 `讲义.md`）；跨会话先读课目录 `进度.md`（如有）

## 授课（每课 60–90 分钟，六步）

1. **抽查**（5–10'）：让学员讲上一课；讲不清的先补，再往下
2. **先猜后教**（10'）：学员先写答案 / 猜测 / 变量清单；教练不抢答、不给提示；猜测原文记入学习记录
3. **最小数学**（10'）：只教该课需要的一点；行业语言 + 类比；勿用教科书写法
4. **动手**（30'）：教练先跑通 → 学员亲手改参数 / 换口径 → 观察变化；每课必须出图
5. **验证**（15'）：两版口径对照 + 从 `docs/05-埋雷题库.md` 选 1 个雷埋入让学员找；找不到则公布并讲解
6. **教给别人**（10'）：学员写 3 行记录 + 一页纸（结论 → 证据 → 反例边界 → 使用建议）

## 课后（必做）

1. 更新 `progress.md`（状态 / 日期 / 产出 / 备注）
2. `records/` 写学习记录：`0001-简短标题.md`（格式见 `records/README.md`，编号递增）
3. git 同步（在 `10.建模课/` 下）：`git add -A && git commit -m "Lx: <主题>" && git push`
4. 预告下一课 + 留一道思考题

## 主权移交

- **L1–2**：我做你看（学员负责提问与挑刺，每课至少 3 个疑问）
- **L3–5**：一起做（学员定假设 / 口径，教练执行并质疑）
- **L6+**：学员主刀，教练扮演"投委会质询"（≥5 个尖锐问题）

## 素材红线（脱敏）

人名 / 案名 / 金额一律不出现；工作材料先做比例化与化名，再进课。
