# 教具安装

## 1. Claude Code 技能（两套）

```bash
# 建模流程（假设预检 / 建模报告 / 代码 / 验证）
npx skills add jihe520/MathModelAgent

# 科研绘图 + draw.io 示意图
npx skills add jihe520/sci-box
```

装完后技能在 `.claude/skills/` 可用；建模课时按需调用（静默待命，不占上下文）。

## 2. 教练技能（本仓库）

```bash
# macOS / Linux
ln -s "$(pwd)/skills/modeling-coach" <vault>/.claude/skills/modeling-coach

# Windows（管理员或开发者模式）
mklink /J "<vault>\.claude\skills\modeling-coach" "<vault>\10.建模课\skills\modeling-coach"
```

装好后在 vault 里说「上建模课」即可触发教练。

## 3. Python 依赖

```bash
pip install numpy pandas matplotlib scipy requests
# 可选（数据刷新 fallback）：pip install yfinance akshare
```

- Python ≥ 3.10（本课程在 3.14 验证）
- 中文出图依赖系统字体：Windows 用 Microsoft YaHei（默认自带）；macOS 用 PingFang SC
