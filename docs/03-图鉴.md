# 图鉴：图 = 问题的形态

> 11 张科研级图（来自 sci-box 技能）与课程的映射。
> 原则：**先想清楚图要回答什么问题，再画**；一图一问。

| 图（模板 id） | 回答什么问题 | 用在 | 提示词示例 |
|---|---|---|---|
| 配对云雨图 `paired-raincloud` | 两组差多少、尾巴多粗 | **L1** | 「画 GOR≥45 与全样本两组的条件收益云雨图」 |
| 相关矩阵组合图 `correlation-pairgrid` | 谁和谁一起动 | **L4** | 「金价、油价、美元、利率的相关矩阵组合图」 |
| CV-ROC 置信区间 `cv-roc-ci` | 分类能力怎样、稳不稳 | **L5** | 「给这个信号做交叉验证 ROC 与置信区间」 |
| 泰勒图 `taylor-diagram` | 多个模型 / 预测谁更准 | **L5** | 「三个油价预测的泰勒图对比」 |
| 半边小提琴相关矩阵 `grouped-corr-split-violin` | 分组后的相关结构 | L4 备选 | 「下三角相关矩阵 + 分组半边小提琴」 |
| 分组环形热图 `grouped-circular-heatmap` | 组间模式一眼看全 | L4 备选 | 「因子分组环形热图」 |
| 组合图 `urban-park-cooling-combo` | 堆叠 + 分布 + 箱线三合一 | L2 备选 | 「压力测试结果组合图」 |
| 多分类 SHAP 组合图 `multiclass-shap-combo` | 模型凭什么这么判断 | 选修 | 「给我模型的 SHAP 蜂群 + 柱状组合图」 |
| 预测-真实值边缘分布 `prediction-marginal-grid` | 预测偏在哪、偏多少 | 选修 | 「预测 vs 真实值边缘分布组合图」 |
| TPE 调参 3D 曲面 `rf-tpe-surface` | 参数与表现的关系面 | 选修 | 「超参数组合的 3D 响应面」 |
| Nature 和弦图 `nature-chord-diagram` | 谁流向谁（流量结构） | 选修 | 「资金流向和弦图」 |

## 怎么渲染（sci-box 模板）

```bash
# 先装：npx skills add jihe520/sci-box
# 然后在工作目录：
python <sci-box技能路径>/scripts/render_template.py <模板id>
```

产出 `outputs/<id>_replica.png/.pdf/.svg`。先出模板原样，再换入自己的数据与中文标注。

## 制图纪律

- 图服务论证：一图一问；说不出"这张图回答什么"就不要画
- 300dpi、PNG + PDF 双格式、字体统一（Microsoft YaHei）
- 灰度可辨；不用无意义渐变和阴影；标题交给图注
- 所有图由脚本生成并入库——课课可复现
