# 定量建模训练场 · 设计稿

> 日期：2026-09-12 ｜ 状态：已批准并实施 ｜ 方法论：superpowers（brainstorming → writing-plans → executing-plans → verification）

## 1. 目标

用已装的建模技能（MathModelAgent / sci-box）+ Claude Code，把"数学建模"训练成工作里的**定量判断力**。不为竞赛、不做研究；每课一个真实问题、一个模型、一张图。

## 2. 核心判断（设计依据）

1. **AI 时代瓶颈是判断力**，不是计算：课程重心 = 翻译问题 / 选对模型 / 验证结果；代码由教练负责，学员亲手改参数、换口径、抓错误。
2. **材料分工**：
   - 流程骨架 ← `2analysis-modeling`（拆解→假设→变量→目标/约束），去竞赛化
   - 防错知识库 ← `_references`（模型菜单 + 题型防错）
   - 图库 ← sci-box 11 张科研图（"图 = 问题的形态"）
   - 教学法 ← `teach` 技能（MISSION / 学习记录 / 最近发展区 / 检索练习）
   - 验收 ← 6verity 精神（数值一致性 / 可复现 / 质询）
3. **学员画像**：金融从业 16 年、业务直觉强、Excel 建模熟、Python 能读；概率统计在补。教学做"确认直觉 → 命名 → 补套路"，不从零教。
4. **教学装置**（针对学员偏好定制）：
   - 先猜后教（第一性原理 + 检索练习）
   - 两版口径对照（学员本就有"双版本测算并存"习惯，升级为标准制品）
   - 埋雷找错（对抗性验证）
   - 教给别人（学员的笔记标准："能教给别人"）

## 3. 关键决策记录

| 决策 | 选择 | 理由 |
|---|---|---|
| 载体 | 全新独立仓库（本仓库） | 学员明确"新做一个项目、不动老仓库" |
| 仓库名 | `Quant-Modeling-Dojo` | 与 `X-from-Zero` 系列同风格；dojo=训练场 |
| 本地位置 | vault `10.建模课/`（独立 git） | 与 08 项目同范式；便于引用工作材料 |
| 首课 | L1 GOR 45 审计 | 招牌指标、材料现成、一节课做完、首课即练"先验证再相信" |
| L1 数据 | 金价 datahub/LBMA（1833+）+ 油价 FRED（1986+），月均值，1987-05 起 | 免密钥、公开、可复现；Yahoo 全量接口返回残缺数据、stooq 维护中，均降级为 fallback |
| 图规范 | 300dpi、PNG+PDF、Microsoft YaHei | 与 sci-box 规范一致 |
| 脱敏 | 案例一律脱敏（化名、比例化金额） | 仓库公开；商业信息零泄漏 |

## 4. 系统结构

```
MISSION.md        # 为什么学
progress.md       # 8 课进度
docs/00-05        # 课表 / 教学协议 / 模型菜单 / 图鉴 / 安装 / 埋雷题库
lessons/L1..L8    # 每课：README（+L1：讲义、脚本、数据、产出）
records/          # 学习记录（0001-…）
skills/modeling-coach/  # 教练技能 → 链入 .claude/skills
```

## 5. 六步仪式（每课）

抽查 → 先猜后教 → 最小数学 → 动手 → 验证（两版对照 + 埋雷）→ 教给别人
主权移交：L1–2 我做你看 → L3–5 一起做 → L6+ 你主刀、我做投委会质询。

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 数据源失效 | 脚本内置多级 fallback（FRED / Yahoo / yfinance / akshare）；快照 CSV 已入库 |
| 工作忙，课程中断 | 进度 + 学习记录无损接续；一课一闭环，不赶进度 |
| 案例敏感 | 脱敏规则写进教学协议（红线） |
| 图不能复现 | 所有图由脚本生成并入库；字体缺失时提示安装 |

## 7. 验收标准（本设计实施完成的定义）

- L1 三步脚本全跑通、出图、数值经 sanity check
- 8 课 README + 6 份 docs + 教练技能就位
- 仓库推送 GitHub 并通过页面验证
