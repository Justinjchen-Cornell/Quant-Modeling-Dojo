# 模型菜单（工作向）

> 去竞赛化的选型速查。遇到问题先定"**输出是什么**"，再选模型族。

## 七种问题形态 → 模型族

| 问题形态 | 你要的输出 | 模型族 | 常用方法 | 对应课 |
|---|---|---|---|---|
| 这个东西可靠吗 | 判断 + 置信度 | 统计分布 | 分位数 / 条件对比 / 基准率 / 稳健性 | L1 |
| 扛得住多坏 | 脆弱点排序 | 敏感性分析 | 单因素扫描 / 情景设计 / 临界点 | L2 |
| 最坏最好到哪 | 概率区间 | 随机模拟 | 蒙特卡洛 / 自助法 / 分位数扇带 | L3 |
| 谁在驱动 | 因子权重与结构 | 回归 / 相关 | OLS / 相关矩阵 / 共线性检查 / 残差诊断 | L4 |
| 行不行 | 评估结论 | 评估方法论 | 交叉验证 / 样本外 / 基准对照 / 置信区间 | L5 |
| 怎么分 | 配置方案 | 优化 | 线性/二次规划 / 有效前沿 / 约束检查 | L6 |
| 改不改判断 | 更新后的信念 | 贝叶斯 | 先验×似然 / 决策树 / 期望值 | L7 |

## 选型三问

1. **输出是什么？** 一个数（优化）/ 一个区间（模拟）/ 一个排序（评价）/ 一个方案（决策）
2. **数据从哪来、样本多大、独立吗？** 样本量决定方法上限；独立性决定显著性是否可信
3. **要"解释"还是要"预测"？** 要解释→简单模型（回归）；要预测→可以用复杂模型，但必须防过拟合

## 工作场景对照

- 判断「贵 / 便宜 / 极端」→ 分布 + 分位（先问：跟什么比？样本多远？）
- 判断「安全边际」→ 敏感性 + 压力测试 + 概率区间
- 判断「该不该做」→ 期望值 + 决策树 + 更新规则
- 判断「谁靠谱」→ 评估纪律（防泄露、样本外、基准对照）

## 常见坑（速查）

- 拿"事后最优"当结论（多重比较 / 过拟合）
- 重叠窗口当独立样本（n 的幻觉）
- 相关当因果；共同趋势造伪回归
- 数据泄露（未来信息混进训练 / 全样本标准化）
- 优化：约束写反、漏约束、不信 `success` 要回代检查
- 贝叶斯类：忽略基础率
