# 课表

> 8 节课，每节 60–90 分钟。每课一个真实问题、一组模型肌肉、一张标配图、一份"教给别人"的产出。
> **真实工作永远可以插队**：哪周手头有定量问题，就用它替换当课案例（这才是目的）。

## 主干

| 课 | 问题（工作语言） | 模型肌肉 | 标配图 | 教给别人（产出） | 主权 |
|---|---|---|---|---|---|
| **L1** | 「GOR 45」这个数可靠吗？ | 分布 / 分位 / 基准率 / 样本独立性 / 稳健性 | 分布图 + 条件对比 + 稳健性矩阵 | 《GOR 45 可信度说明》 | 我做你看 |
| **L2** | 现金流扛得住多坏的情况？ | 情景 vs 敏感性 / 临界点 | 龙卷风图 + 双因素热图 | 《最脆的三块木板》 | 我做你看 |
| **L3** | 最坏最好会到哪？概率多大？ | 蒙特卡洛 / 相关性 / 分位数 | 分位数扇带 + 分布图 | 《结果概率区间说明》 | 一起做 |
| **L4** | 谁在驱动结果？ | 回归 / 相关结构 / 共线性 / 残差 | 相关矩阵组合图 | 《驱动因子清单》 | 一起做 |
| **L5** | 凭什么说一个策略/模型"行"？ | 交叉验证 / 防泄漏 / 过拟合 | CV-ROC + 泰勒图 | 《评估检查清单》 | 一起做 |
| **L6** | 有限资源怎么分？ | 约束优化 / 有效前沿 | 有效前沿 + 权重图 | 《配置方案对照》 | 你主刀 |
| **L7** | 新证据来了，改不改判断？ | 贝叶斯更新 / 决策树 | 决策树 + 后验图 | 《判断更新规则卡》 | 你主刀 |
| **L8** | 出师演练：全流程独立走 | 六步全链条 | 技术路线图 + 一页纸 | 一次完整交付 | 你做我审 |

## 主权移交路线

- **L1–2 我做你看**：教练示范完整流程、边做边讲；学员负责提问与挑刺（每课至少提 3 个疑问）
- **L3–5 一起做**：学员定假设与口径，教练执行并质疑
- **L6+ 你主刀**：学员主导全流程，教练扮演"投委会质询"

## 节奏与中断

- 每周 1–2 课；不必连续，中断后用 `progress.md` + `records/` 无损接续
- 每课都以完整闭环结束（不拖着半课过夜）；卡住就停在第 3 步"最小数学"，下次续

## 素材池

| 类型 | 可用材料 | 脱敏要求 |
|---|---|---|
| 指标/信号 | 招牌指标（GOR 类） | 公开数据可直接用 |
| 现金流/测算 | 投资测算、压力测试表 | 比例化金额、化名项目 |
| 策略/模型 | 策略库任选一个 | 隐去标的与参数细节 |
| 数据 | 框架数据、宏观序列 | 公开数据优先 |
| 判断场景 | 任意"改不改主意"的真实时刻 | 化名涉事方 |

## 出师标准

1. 全新问题 30 分钟内写出变量 / 假设 / 目标 / 约束的口径清单
2. 能识别并拒收带数据泄露、幸存者偏差或口径错误的分析
3. L8 全流程独立完成，守得住"投委会式质询"
