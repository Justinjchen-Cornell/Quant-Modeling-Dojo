# 埋雷题库（教练专用）

> 机制：验证步由教练**悄悄**埋入 1 个错误做法，混进结果里让学员找。
> 找到 → 讲透；找不到 → 公布答案并讲解。难度随课程递进。

## L1 · 指标可靠性

**雷 1（事后最优阈值）**：把阈值从 40 到 60 全部扫一遍，挑一个"表现最好"的（比如 42），然后宣称"当 GOR≥42 时上涨概率最高"。
- 学员应指出：这是多重比较 / 过拟合；阈值应该是**事先**定好的（或做样本外验证），不是从数据里挑的。

**雷 2（重叠窗口当独立样本）**：用月度数据算 12 个月持有期收益，宣称"n=312 个样本，68% 上涨，统计显著"。
- 学员应指出：相邻样本高度重叠，独立事件数 ≈ n/12；有效样本极小，不能按 312 个独立样本谈显著性。

**雷 3（起点选择 / 幸存者偏差）**：只从某个特定年份（如 2015）起算，恰好"验证"了结论。
- 学员应指出：起点决定结论 = 不稳健；应展示多起点网格（step3 的作用）。

**L1 埋雷操作**：在 step2/step3 讲解时，教练口头给出"雷版"结论（或临时改一个参数重跑），学员对照自己跑出的结果说破。

## L2 · 压力测试

- 只动一个变量，却声称"做了全面压力测试"（漏掉联动）
- 扰动幅度拍脑袋（±50% 没有依据），或只在"舒适区"内扰动

## L3 · 蒙特卡洛

- 输出漂亮分布，但输入变量假设相互独立（实际高度相关）
- 不固定随机种子 → 结果每次不一样；或跑 100 次就下结论（收敛性不查）

## L4 · 归因

- 把相关当因果（"油价涨所以金价涨"）
- 两个共同趋势的序列做回归，R² 很高但无意义（伪回归）；不查残差与共线性

## L5 · 评估纪律

- 数据泄露：用全样本标准化 / 未来信息混入特征
- 在测试集上调参 / 反复换指标直到"好看"（多重比较）；不设基准对照

## L6 · 优化

- 约束写反（≥ 写成 ≤）或不回代检查约束
- 角点解直接报（100% 押一个资产）却不解释假设与鲁棒性

## L7 · 贝叶斯

- 忽略基础率（"检测 90% 准，所以阳性就是 90% 有病"）
- 先验拍脑袋且从不做敏感性（先验变化后结论大反转也未察觉）

## L8 · 综合

- 全流程里任一环节的雷都可以用；重点考"独立发现 + 说清代价"
