# 学习记录

> 只记"学会了什么"，不记"讲了什么"。每条一屏以内。

## 格式

文件名：`0001-简短标题.md`（编号递增）

```markdown
# 简短标题

1–3 句：学会了什么（或确认了什么已知能力），以及它为什么影响接下来的教法。

## 可选
- **证据**：怎么证明学会了（回答的问题 / 完成的练习）
- **影响**：它解锁或排除了什么
```

## 什么时候写
- 学员展示了某概念的真实理解（不是"听过"，是"能用对"）
- 学员披露了先验知识（"这个我早会了"）——记录深度，避免重复教
- 纠正了一个误解（高价值：预测未来绊脚石）
- 使命发生了变化（同步更新 `MISSION.md`）
