# L8 · 出师演练 —— 全流程独立走一遍

**问题**：一个全新问题，从零走到"可交付"。没有示范，只有质询。
**模型肌肉**：六步全链条 + 沟通
**标配图**：技术路线图（scibox-diagram）+ 一页纸
**主权**：你做我审（教练 = 投委会）

## 规则
1. 学员自选一个**真实且尚未做过**的定量问题（教练只做脱敏检查）
2. 学员独立完成：翻译 → 假设 → 选型 → 执行 → 验证 → 表达
3. 教练全程只做两件事：投委会式质询 + 记录决策点
4. 最多 2 次会话完成；跨会话在课目录留 `进度.md`

## 六步要求（学员版）
1. 翻译：变量 / 假设 / 目标 / 约束的口径清单（30 分钟内）
2. 选型：给出至少 2 个候选模型与取舍理由
3. 执行：指挥 AI 完成计算（教练旁观，不给提示）
4. 验证：两版口径对照 + 自己设计 1 个反例测试
5. 表达：技术路线图（drawio）+ 一页纸（结论 / 证据 / 边界 / 建议）
6. 质询：教练提出 ≥5 个尖锐问题，学员守得住 ≥4 个

## 验收（出师标准）
- 口径清单完整、假设写得出"不成立时会怎样"
- 验证环节是自己想到的，不是被提醒的
- 质询中不回避、不硬撑：会区分"数据支持"与"我的判断"
- 一页纸能让外行复述

## 产出
- 完整 case 文件夹（脚本 + 图 + 报告 + 决策记录）
- 教练的质询记录与评审意见
- 出师纪念：case 脱敏后可作为示范课案例
