# L7 · 贝叶斯更新 —— 新证据来了，改不改判断？

**问题**：你对一件事有先验判断；来了新证据。该改多少？怎么改得有理有据？
**模型肌肉**：先验 / 似然 / 后验 / 基础率 / 更新规则
**标配图**：决策树 + 后验分布图
**主权**：你主刀

## 先猜
1. 一个"90% 准确"的检测，阳性就意味着 90% 有问题吗？你的直觉是多少？
2. 你的投资判断里，"先验"通常是什么（经验 / 基准率）？
3. 什么证据才配让你大改判断？

## 最小数学
- 贝叶斯公式：后验 ∝ 先验 × 似然；用"袋中摸球"和"检测悖论"讲
- 基础率：99% 都正常的世界里，再准的检测也难摆脱大量假阳性
- 序列更新：今天的后验 = 明天的先验；证据要"相对独立"才算数
- 敏感性：先验动一点，后验动多少？什么时候结论会反转

## 动手
1. 选一个真实判断场景（如"某类资产进入低估区"或"重整成功"）
2. 写下先验（基准率：历史上这类事件发生频率）与证据（似然）
3. 算后验；再换一个先验重算，找结论反转的门槛
4. 学员亲手改：把证据强度砍半，后验怎么变？

## 验证
- 两版对照：不同先验 / 不同证据口径
- 埋雷：忽略基础率（`docs/05` L7）

## 教给别人
一页纸《判断更新规则卡》：先验来源 + 证据清单 + 更新后的置信度 + 下次更新的触发条件

## 材料与产出
- 材料：任意判断场景（化名）
- 产出：决策树 / 后验图、更新规则卡

## 验收
- 能当场用贝叶斯解释"检测 90% 准"为什么不等于"阳性 90% 有问题"
- 更新规则卡能被别人照着用
