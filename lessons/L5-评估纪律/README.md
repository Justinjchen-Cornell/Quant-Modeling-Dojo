# L5 · 评估纪律 —— 凭什么说一个策略/模型"行"？

**问题**：一个信号 / 策略 / 预测模型宣称"有效"，你怎样在 30 分钟内判断它是不是幻觉或骗局？
**模型肌肉**：训练/验证划分 / 防数据泄露 / 交叉验证 / 基准对照 / 样本外 / 过拟合识别
**标配图**：CV-ROC 置信区间（sci-box `cv-roc-ci`）+ 泰勒图（`taylor-diagram`）
**主权**：一起做

## 先猜
1. "回测年化 40%" 这句话里，最可能藏猫腻的三个地方？
2. 为什么要留"样本外"？不留会怎样？
3. 一个策略调过多少次参数，算"调多了"？

## 最小数学
- 数据泄露：未来信息混进当下（全样本标准化、用未来数据筛标的）
- 训练 / 验证 / 测试三分与走查（walk-forward）：时序不能随机打乱
- 多重比较：试 100 个策略总有 5 个"显著"——不是策略赢了，是统计使然
- 基准对照：跑赢"什么都不做"（买入持有 / 随机）才算有本事
- 置信区间：给胜率 / 夏普加误差棒；不稳的"好"不是好

## 动手
1. 取策略库一个策略（或教练准备的"疑似过拟合"教学案例）
2. 做三件事：正确的样本外评估 + 打乱数据再跑一遍（若仍"有效"→ 警报）+ 与基准对照
3. 输出：评估表（样本内 / 样本外 / 基准 / 置信区间）
4. 学员亲手改：把测试集"偷看"一次（调参），看样本外结果怎么恶化

## 验证
- 两版对照：随机打乱 vs 真实顺序；不同起止年份
- 埋雷：测试集调参 / 只报最优回测（`docs/05` L5）

## 教给别人
一页纸《评估检查清单》：泄露 / 样本外 / 基准 / 多重比较 / 成本 五问

## 材料与产出
- 材料：策略库任选（隐去标的与参数）
- 产出：CV-ROC、泰勒图、评估表；一页纸

## 验收
- 能当场指出一个"漂亮回测"里最可疑的两处
- 会向别人解释"为什么试多了会赢"
