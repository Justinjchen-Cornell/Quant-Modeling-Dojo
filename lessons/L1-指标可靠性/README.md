# L1 · 指标可靠性 —— "GOR 45"这个数可靠吗？

**问题**：一个广为引用的阈值型指标（GOR ≥ 45 → 原油极端低估，"历史说"后 12–24 个月涨 54–167%）。先别信，先验。
**模型肌肉**：分布 / 分位数 / 条件对比与基准率 / 样本独立性 / 稳健性
**标配图**：GOR 历史与分布；条件收益 vs 基准对照；稳健性矩阵
**主权**：我做你看（你负责挑刺）

## 这一课练什么

判断一个"数字规律"的可靠性。学完你会对任何"过去 N 次都这样"的说法条件反射地问四个问题：

1. 这个数在**分布**里是什么位置？（分位数）
2. **对照组**是什么？（基准率——不能跟"零"比）
3. 样本真的**独立**吗？（重叠窗口 → n 的幻觉）
4. 换个起点 / 阈值 / 口径还**稳**吗？（稳健性）

## 六步

1. **开场（10'）**：三问摸底（首课）：你现在的定量工作流程是什么？哪一步最虚？最想验证哪一个"数"？
2. **先猜（10'）**：45 这个数怎么来的？如果今天让你验证它，你先查什么？写下答案（进学习记录）
3. **最小数学（10'）**：见 `讲义.md` 第 2 节
4. **动手（30'）**：三个脚本依次跑（见下）；每步先看输出数字，再改一个参数重跑，观察变化
5. **验证（15'）**：两版口径对照（全部月份 vs 首次穿越事件）+ 找教练埋的雷（`docs/05-埋雷题库.md` L1）
6. **教给别人（10'）**：写一页《GOR 45 可信度说明》，结构见 `讲义.md` 第 5 节

## 数据

`data/gor_monthly.csv`：金价与布伦特 / WTI 油价的**月度均值**序列，**1987-05 起（472 个月）**。
来源（免密钥、可复现）：

- 金价：datahub.io 月度金价（LBMA，该序列可回溯至 1833 年）
- 油价：FRED 公开 CSV（Brent 1987+ / WTI 1986+，日频 → 月均值）
- 长样本：`data/gor_long.csv`（金价 × WTI 月价，1946+；1971 前为布雷顿森林固定金价，仅供背景）

刷新（可选，需要网络）：`python scripts/fetch_data.py`
