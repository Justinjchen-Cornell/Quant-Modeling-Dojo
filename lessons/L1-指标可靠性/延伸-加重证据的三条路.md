# 延伸 · 给结论"加重量"的三条路

> 来自 L1 结尾：想让"45 这样的结论"变得更可依赖，只有三条路——各自修一个洞。

## 总览

| 路径 | 修的洞 | 一句话 |
|---|---|---|
| ① 跨体制样本 | 样本太少（56 年只有 2 个"世界"） | 横向找平行世界，把 n 从 2 抬起来 |
| ② 机制论证 | 不知道为什么涨、何时会失效 | 把数字升级成因果链 + 可监控的中间变量 |
| ③ 事前注册 | 容易自己骗自己（挑数据 / 事后编故事） | 先写规则、再看数据、全程留痕 |

---

## ① 跨体制样本：找"N 个平行世界"

### 问题
金油比 56 年只有 2 个宏观世界（疫情 2020、黄金重估 2025-26）。统计推断要的是"一批可比较的独立案例"——时间轴给不了，横截面也许能给。

### 办法：把假说抽象成"现象类"，再去收集平行实现
1. **抽象**：不研究"金油比 45"，研究"**比值型估值指标触及历史极端后，是否均值回归**"。
2. **建样本池**（每一个都是一次平行检验）：
   - 金银比（1991、2020 达 ~125 历史极值）、铜金比、股债比（ERP）、CAPE、高收益信用利差……
   - 每个池子里按课上标准数**独立事件**（首次穿越，不是月份）。
3. **算行业基准率**：平行世界里"极端后 12–24 个月回归"的胜率、中位时滞、最差情形各是多少？你的 45 排第几档？
4. **汇报升级**：不说"历史上涨了 54–167%"，改说"12 个平行案例中，9/12 在 24 个月内收敛，中位 +38%，最差 -25%"。

### 局限（必须写明）
- 平行世界**不独立**：2020 年所有比值一起极端（共同因子=全球流动性）→ 要分组（危机 vs 常态）。
- **外部效度**：金银比（避险/工业）与金油比（货币/能源）机制不同——提高可信度可以，直接搬数字不行。
- 跨币种 GOR 增益有限（汇率腿抵消、仍是同一个世界）；真正的"多世界"是跨国宏观案例（70s 美英、80s 拉美、90s 俄罗斯、2020s 全球）。

## ② 机制论证：把数字升级成因果链

### 问题
数字说"过去涨"，不说"为什么涨、什么时候不涨"。L1 亲手拆过腿：2020=油崩型（支持"油被错杀"）、2025-26=金涨型（不支持）。**同一条规则、两种机制，只有一种能被支持。**

### 办法：五步拆机制
1. **写因果链**（GOR 版候选）：
   - 链 A 供给予衡：油 < 边际成本 → 减产 / 资本开支收缩 → 供给收缩 → 价格回归；
   - 链 B 冲击-修复：极端 GOR = 需求崩塌事件 → 事件结束 → 修复（2020 的机制）；
   - 链 C 金融化：极低油价 → 期货超级升水 → 囤油套利 → 现货抽紧；
   - 链 D 货币腿：金价重估 → GOR 被动抬高（2025-26 的机制）→ **对"油涨"没有支持**。
2. **每环配可观测指标**：页岩盈亏线、OPEC 财政平衡价、钻机数、库存、CFTC 持仓、期货曲线结构。
3. **写失效条件**：需求永久破坏（能源转型）、卡特尔破裂、替代加速。
4. **检验中间变量**：机制若对，中间变量应**先动**。当前关键不是 GOR=48，而是：油价在边际成本之下吗？供给在收缩吗？——若否，链 A 未启动。
5. **机制筛选**：判词里的"二次确认（油价绝对低位 + VIX）"就是雏形——升级为清单：先拆腿（金腿/油腿）→ 判冲击类型（供给/需求）→ 查供给弹性。

### 为什么机制更"跨体制"
"低于边际成本 → 减产"这条规律在 1986 / 1999 / 2016 / 2020 都工作过——机制类证据天然比一条价格序列跨越更多世界，可与路径①互相喂养。

### 防骗条款
机制也是叙事，泡沫也有故事。唯一的防骗办法：**每条机制必须给出可证伪的预测**——"如果机制对，应该看到 X（而我现在还没看到）"。写下来，去查 X。

## ③ 事前注册：先写规则，再看数据

### 问题
L1 的反面教材：扫描 40–55 挑最优——没有事前规则，你分不清一个结论是"发现"还是"抓阄"。三个敌人：挑数据（data snooping）、事后编假设（HARKing）、只报赢的（选择性报告）。

### 四个工具
1. **分析计划书（前向注册卡）**——一页五行：
   ```text
   【前向注册卡 · GOR 45】编号 2026-001
   写下：日期、当下状态（GOR=48，金腿主导）
   预测：若 3 个月内 GOR 回落 <40，主因应为 ____（油涨 / 金跌）
   判据：12 个月后 Brent 超额 > __% 记命中；< 0% 记失败
   到期对账，严禁修改本卡
   ```
2. **前向检验**：把未来当真正的样本外。触发时先写"剧本"（预期、期限、成功判据），到期对账。**3 次前向触发 > 300 次回测观察**（前提：写在触发之前）——慢，但干净。
3. **尝试台账**：试过的每个阈值 / 窗口 / 起点都记一行；报告时披露全部（试过 m 个只报最优 → 结论打对折再打对折）。
4. **规则版本化**：框架已有版本号（v2.1）、每日快照、"公开证伪条款"——这些都是个人版事前注册的零件。补最后一块：**每次改规则，先 git commit"愿望版"，再回测**——让数据永远跑在规则之后。

### 局限
注册防"自欺"，不防"世界的恶意"——注册过的假说照样会输。它的作用是把"骗自己"这条路堵死，把能赢的证据留下。

---

## 收束

- 各修一个洞：**样本 · 因果 · 自欺**。
- 性价比排序（个人）：**事前注册（今天就能做）＞ 机制论证（每次研究都做）＞ 跨体制面板（选做重活）**。
- 三条都做了，也不产生确定性——只是把"2 个故事"变厚成"一批证据"。**决策依然要在不确定下做：用期望值、仓位、止损，而不是用"自信"。**
- 课程地图：L3（不确定性的量化）· L4（机制的家：归因）· L5（事前注册与样本外的家：评估纪律）。
