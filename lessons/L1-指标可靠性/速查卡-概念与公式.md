# L1 速查卡 · GOR 45 审计 —— 概念与公式（深入浅出版）

> 复盘用。公式用 LaTeX 书写（Obsidian / GitHub 可直接渲染）；每个公式后面都跟着"人话"。

## 0. 一页话回顾

- **课的问题**：阈值型宣称（GOR≥45 → 油价涨 54–167%）可不可信？
- **课的答案**：方向可能真；证据很薄；**当报警器，不当规律**。
- **课的方法**：把一个大宣称，拆成五个可以分别检验的小问题。

## 1. 六个核心概念

### ① 分位数：阈值只是分布上的一条刻度

- 公式：$\hat{p} = P(X \le x) = \dfrac{\#\{x_i \le x\}}{n}$
- 人话：45 不是客观真理线，它是"历史上 96.3% 的时间 GOR 比它低"这句陈述的简写。
- L1 实测：45 = P96.3；≥45 仅 3.7% 时间（56 年 25 个月）；前 49 年 0 次（最高 39.6，2016-02）。
- 用法：看到任何"危险线 / 合理区间"，先把它还原成分位。

### ② 基准率：涨了 ≠ 有信号

- 公式：条件均值 $E[R\mid c] = \dfrac{1}{n_c}\sum_{i \in c} R_i$；超额 $\Delta = E[R\mid c] - E[R]$
  （$R$ = 未来持有期收益；$c$ = 触发条件的样本）
- 人话：跟"什么都不做"比，别跟 0 比——原油躺着 12 个月平均也涨 10.2%。
- L1 实测：条件 +86%~89% vs 基准 +10.2% → 超额 +76~79pp。方向成立。
- 用法：任何"XX 之后涨了 Y%"的宣称，第二个问题永远是"基准是多少？"

### ③ 重叠窗口：照片数 vs 事件数（本课最重要）

- 公式（粗略估计）：同一段连续满足期内，$n_{\text{eff}} \approx n / h$（$h$ = 持有期月数）
- 更稳的做法：直接数**独立事件**（首次穿越次数）$n_{\text{events}}$
- 人话：连续 3 个月满足条件、看的是几乎同一段未来——像连拍相机拍了 3 张**同一次**抛硬币。统计的底气，管的是"几次经历"，不是"几个月度"。
- L1 实测：n=10 个月 → 独立事件 3 个（12 个月口径）/ 2 个（18 个月口径）。
- 用法：任何"X 次里 Y 次都对"的说法，先问"这 X 是几场戏拍的？"

### ④ 显著性直觉：为什么"几次经历"决定一切

- 公式（直觉版）：$t \approx \dfrac{\Delta}{\sigma/\sqrt{n_{\text{eff}}}}$ —— 分母里是 $n_{\text{eff}}$ 的**平方根**。
- 人话：$n_{\text{eff}}$ 从 100 掉到 4，$t$ 值缩水 $\sqrt{25}=5$ 倍——"铁证"变"查无实据"。
- 抛硬币参照：连 3 次正面 = 12.5%（运气做得到）；连 10 次**独立**正面 = 0.1%（才叫证据）。
- 用法：看到"胜率 100%"，先找 $n_{\text{eff}}$；找不到就不用往下看了。

### ⑤ 多重比较：挑出来的冠军不是冠军

- 公式：$P(\text{至少一次假阳性}) = 1 - (1-\alpha)^m$（试 $m$ 次、每次假阳性率 $\alpha$）
- 人话：扫 40→55 挑最好的——试的维度越多，越必有"赢家"（$m=14,\ \alpha=5\%$ → 超 50% 概率撞上一个假货）。
- L1 实测：55（+183%）的 n=2——"最纯"其实是"最少"。
- 纪律：要么**先定后验**（先写规则、再看数据），要么**样本外验证**。

### ⑥ 拆腿：比值动了，先问"谁动的"

- 公式：$\Delta \ln \text{GOR} = \Delta \ln \text{Gold} - \Delta \ln \text{Oil}$（对数贡献分解；或近似：GOR 变化率 ≈ 金价变化率 − 油价变化率）
- 人话：比值 = 分子 ÷ 分母。GOR 冲高可能是"油崩"（分母崩）或"金涨"（分子涨）——**病因不同，药方不同**。
- L1 实测：2020 = 油 −67% / 金 +5%（油崩驱动，反弹逻辑成立）；2025-26 = 金 +59% / 油 −12%（黄金驱动，"油被错杀"前提不成立）。
- 用法：任何比率型指标（PE、金银比、金油比、信用利差），动之前先拆腿。

## 2. 五问速查（随身携带版）

任何"阈值 / 规律型"宣称，五问：

1. **分位**：这个阈值在分布里站哪？（"极端"名副其实吗）
2. **基准**：跟"什么都不做"比，差多少？（方向有没有超额）
3. **事件数**：n 是几张照片、几个事件？（$n_{\text{eff}}$ 支撑得起结论吗）
4. **稳健**：换起点 / 换阈值 / 换口径还成立吗？（还是某个窗口的产物）
5. **机制**：数字背后是什么在驱动？（流动性 / 供给 / 重估——数字是标签，机制才是内容）

> 五问全过 → 可用；任何一问塌 → 降级为观察项。
> L1 判决：① 过（称职的极端标记）；② 成立但薄；③ 塌（独立事件仅 2–3 个）；④ 结构敏感（4 段 ↔ 2 段）；⑤ 在"黄金驱动"下失效。→ **观察区，不是触发线。**

## 3. 术语对照表

| 术语 | 英文 | 人话 |
|---|---|---|
| 分位数 | percentile | "历史上多少比例比它低" |
| 基准率 | base rate | "什么都不做"的平均结果 |
| 条件收益 | conditional return | "信号出现后"的平均结果 |
| 重叠窗口 | overlapping windows | 相邻观测共享同一段未来（照片重叠） |
| 有效样本 | effective n | 独立经历的个数（事件数） |
| 多重比较 | multiple comparisons | 试得越多、越容易"找到"假货 |
| 数据窥探 | data snooping | 先看数据、再定规则（马后炮） |
| 样本外 | out-of-sample | 用没看过数据的那部分检验 |
| 稳健性 | robustness | 换口径后结论动不动 |
| 幸存者偏差 | survivorship bias | 只看到活下来的样本 |
| 拆腿 | leg decomposition | 比值变动归因到分子 / 分母 |

## 4. 三个常见误区（自检用）

1. ❌"涨了，所以信号有效" → ✅ 跟基准比（+86% vs +10%，差的那部分才叫信号）
2. ❌"18 次里 16 次对，好准" → ✅ 先数独立事件（可能是 2 场戏拍的 18 张照片）
3. ❌"扫一圈找到最优参数" → ✅ 那是挑冠军；先定后验，或样本外
