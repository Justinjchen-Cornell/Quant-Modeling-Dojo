# L1 讲义 · 指标可靠性

> 课上对照用、课后复习用。教练在"最小数学"与"动手"环节引用本文。

## 1. 背景：一个 45 的故事

一个流传很广的宏观指标：**GOR = 金价 ÷ 油价**（Gold-Oil Ratio）。主张是：

> "GOR 升破 45 = 原油极端低估。历史回看，之后 12–24 个月油价上涨 54–167%。"

这类主张在投资语境里到处都是：一个阈值 + 一组历史统计 + 一个方向性结论。
本课不预设立场——**先把它当成一个待验证的模型**，完整走一遍验证流程。

## 2. 最小数学（四个概念）

### 2.1 分布与分位数

任何"极端"都是相对分布而言的。45 是不是极端，取决于 GOR 的历史分布长什么样：

- 中位数、90 / 95 / 99 分位分别是多少？
- 45 落在哪个分位？"极端"是 95 分位还是 99 分位？
- 换个起点（2000 vs 2010），分位会怎么动？

### 2.2 条件对比与基准率

"GOR≥45 之后涨了 X%"——这个 X% 要跟什么比？

- **错的比法**：跟 0 比（"涨了就是有效"）
- **对的比法**：跟**基准率**比——全样本里，任意时点往后 12 个月的收益率是多少？
- 只有条件收益**显著高于**基准收益，才谈得上"预测力"；否则只是"油价长期上涨"的另一种说法。

### 2.3 样本独立性（n 的幻觉）

用月度数据算"未来 12 个月收益"，相邻月份高度重叠：

- 312 个月度观测 ≠ 312 个独立样本；12 个月重叠窗口 → 独立样本大约只有 1/12
- "18 次里 16 次上涨"听起来很强——但如果这 18 次其实只来自 2 个独立事件呢？
- 正确做法：数**独立事件**（首次穿越），而不是数月度数。

### 2.4 多重比较（挑出来的"最好"）

把 40、45、50、55 全扫一遍，然后报告"表现最好的那个阈值"：

- 这不是发现规律，是**从噪声里挑冠军**（试得越多，越容易"找到"）
- 纪律：阈值要么事先定（先有逻辑，再看数据），要么做样本外验证
- 延伸：这与"回测骗局"是同一个数学（L5 再见）

## 3. 三步动手

每一步都是：**先看数字 → 改一个参数 → 再看数字**。你要亲手改。

### 第 1 步：分布与分位（step1_distribution.py）

- 看什么：样本区间 / 中位数 / 90、95、99 分位 / 45 的位置 / ≥45 的时间占比 / ≥45 的独立片段数
- 改什么：把阈值线从 45 改成 40 或 50，观察"极端"的叙事怎么变

### 第 2 步：条件收益 vs 基准（step2_conditional_returns.py）

- 看什么：两种口径的对比 —— 口径 A"所有 GOR≥45 的月份"（重叠样本）；口径 B"首次穿越事件"（独立事件）
- 关键指标：条件均值 / 中位数 / 胜率 vs 全样本基准；两者差距
- 改什么：持有期 12 → 6 / 24 个月；资产 Brent → WTI

### 第 3 步：稳健性网格（step3_robustness.py）

- 看什么：起点 × 阈值 × 持有期的组合网格里，结论（条件均值 − 基准、胜率）稳不稳
- 改什么：找出结论最敏感的那个维度（起点？阈值？）
- 记住：**稳健性比显著性更重要**——换个合理口径就翻的结论，不能当决策依据

## 4. 验证设计（课上执行）

1. **两版口径对照**：口径 A（月份样本）vs 口径 B（穿越事件），差异写进笔记
2. **找埋雷**：教练按 `docs/05-埋雷题库.md` L1 节埋雷（不预告），你要说破
3. **自检四问**：分位 / 基准 / 独立性 / 稳健性，各给一句话结论

## 5. 教给别人：一页纸模板

《GOR 45 可信度说明》

```text
结论（一句话）：
  45 这个阈值属于（可靠 / 不可靠 / 有条件可靠），最重要的一条理由是 ____。

证据（三条以内）：
  1) 分位：45 位于历史 ___ 分位，≥45 时间占比 ___%
  2) 对照：条件收益 ___% vs 基准 ___%（口径：___）
  3) 独立事件：真正独立的"穿越事件"只有 ___ 次

反例边界（什么时候结论失效）：
  - 起点换成 ___ 后，结论变成 ___
  - 阈值换成 ___ 后，结论变成 ___

使用建议：
  把它当 ___ 用（信号 / 参考 / 不能用）；触发时先检查 ___。
```

写完读一遍：一个外行能不能复述你的结论和最大风险？

## 6. 延伸

- **更长历史**：本课 GOR 从 1987-05 起（受布伦特油价源限制）；金价本身可回溯至 1833 年（LBMA），升级空间在更早的油价源
- **换题练**：把"45"换成你工作里另一个阈值型规则，重跑三步——流程完全一样
- **预习**：本课的"重叠窗口"与"多重比较"，是 L5"回测骗局"的两个数学内核
