# L4 · 归因与关系 —— 谁在驱动结果？

**问题**：一个结果（收益率 / 销量 / 违约率）到底被什么驱动？"一起动"和"驱动"差多远？
**模型肌肉**：相关结构 / 简单回归 / 共线性 / 残差诊断 / 伪回归识别
**标配图**：相关矩阵组合图（sci-box `correlation-pairgrid`）
**主权**：一起做

## 先猜
1. 列出 5 个你相信会影响结果的变量：谁是"领导"、谁是"跟班"？
2. R² 很高就说明找对了吗？
3. 什么情况下两个毫无关系的序列会高度相关？

## 最小数学
- 相关系数只描述"一起动"，不描述"谁驱动谁"
- 回归 = 控制其他变量后的平均关系；系数含义与量纲
- 共线性：两个高度相关的输入会让系数不稳（谁背锅说不清）
- 伪回归：共同趋势（都随时间涨）让无关序列 R² 很高——看残差、做差分、查样本外
- 残差诊断：模式化残差 = 模型漏了什么

## 动手
1. 取一组数据（框架数据 / 市场序列，公开数据优先）
2. 先画相关矩阵组合图（全景观感），再做一个简单回归
3. 输出：系数表 + 残差图 + 共线性检查（VIF）
4. 学员亲手改：删 / 加一个变量，看其他系数怎么动（共线性的体感）

## 验证
- 两版对照：全样本 vs 去掉一个极端区间；水平值 vs 差分
- 埋雷：相关当因果 / 伪回归（`docs/05` L4）

## 教给别人
一页纸《驱动因子清单》：哪些是真候选、哪些只是搭便车、还缺什么证据才能称因果

## 材料与产出
- 材料：框架数据 / 市场序列（公开数据优先）
- 产出：相关矩阵组合图、回归摘要、一页纸

## 验收
- 能解释：为什么"控制变量后"的系数才是模型说的；伪回归怎么识别
- 在相关矩阵图上能指出结构性关系（分块 / 离群）
