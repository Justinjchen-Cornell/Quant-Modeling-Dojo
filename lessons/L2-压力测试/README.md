# L2 · 压力测试 —— 现金流扛得住多坏的情况？

**问题**：一版投资测算 / 现金流模型，改哪些变量会让它从"可行"变"危险"？多坏才算坏？
**模型肌肉**：情景分析 vs 敏感性分析；临界点；脆弱点排序
**标配图**：龙卷风图（单变量敏感度排序）+ 双因素热图
**主权**：我做你看

## 你要先答的三个问题（先猜）
1. 所有变量里，哪三个最可能让现金流崩掉？排个序，写下理由
2. "压力测试"和"敏感性分析"的区别是什么？
3. 扰动 ±20% 和 ±50%，哪个更该看？为什么？

## 最小数学
- 敏感性 = 离散版偏导数：一次只动一个变量，看输出变化率
- 情景 = 一组变量联动的"故事"（如"滞销 + 融资收紧"同时发生）
- 两者互补：敏感性找脆弱点，情景测组合拳；非线性区间（阈值 / 拐点）是关键
- 临界点：变量恶化到什么程度，结论翻转（可行 → 不可行）

## 动手（30'）
1. 取一版脱敏现金流模型（教练把 Excel / 脚本改成可参数化版本）
2. 扰动 5 个变量：销售均价 / 去化率 / 融资利率 / 工期 / 建安成本，各 ±10 / 20 / 30%
3. 输出：每个变量的影响排序 + 临界点表格
4. 学员亲手改：挑一个变量把扰动幅度加大到 ±50%，观察是否出现非线性拐点

## 验证（15'）
- 两版对照：单因素扫描 vs 三变量联动情景，差异写清楚
- 埋雷：只调一个变量却声称"全面压力测试"（见 `docs/05-埋雷题库.md` L2）

## 教给别人（10'）
一页纸《最脆的三块木板》：变量排序 + 临界点 + 监控建议（哪个指标到什么值该报警）

## 材料与产出
- 材料：任意一版投资测算 / 现金流表（脱敏：比例化金额、化名项目）
- 产出：`outputs/` 龙卷风图、热图、临界点表；一页纸

## 验收
- 能说出：敏感性 ≠ 情景；为什么排序比绝对值重要；非线性区间在哪
- 龙卷风图一眼看出 Top3 脆弱变量
