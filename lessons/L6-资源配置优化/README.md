# L6 · 资源配置优化 —— 有限资源怎么分？

**问题**：资金 / 额度 / 清偿资源有限，怎么分才"最优"？"最优"是谁的最优？
**模型肌肉**：目标函数 + 约束的思维 / 线性与二次规划直觉 / 有效前沿 / 约束回代检查
**标配图**：有效前沿 + 权重图（自绘，风格对齐 sci-box）
**主权**：你主刀（教练质询）

## 先猜
1. "收益最大化"作为目标有什么问题？你会加什么约束？
2. 约束里哪一条最可能被"吃掉"（不满足）？
3. 为什么"全押一个"的最优解往往不是答案？

## 最小数学
- 优化 = 目标 + 约束；先写清楚这两样，再谈算法
- 线性 vs 二次：风险是"平方"的，组合优化天然是二次型直觉
- 有效前沿：想要更高收益必须接受更高风险
- 约束回代检查：解出来必须逐条验证（写反的约束会给出荒谬解）

## 动手
1. 定一个真实资源分配问题（仓位分配 / 清偿顺序 / 额度切分）
2. 写下：目标（收益 / 回收率 / 成本）+ 约束（上限 / 下限 / 预算 / 流动性）
3. 跑两版：最大化收益 vs 最大化风险调整后收益（或加约束后），对比
4. 学员亲手改：放松 / 收紧一个约束，看方案怎么跳——体会"约束是主角"

## 验证
- 两版对照：不同目标函数 / 不同约束设定
- 埋雷：约束写反不回代 / 角点解不解释（`docs/05` L6）

## 教给别人
一页纸《配置方案对照》：两版方案 + 各自代价 + 推荐与适用条件

## 材料与产出
- 材料：任意分配场景（脱敏）
- 产出：有效前沿图、权重图、对照表；一页纸

## 验收
- 能写出完整的目标 + 约束清单，并逐条回代验证
- 能解释"为什么这个解在角上"（或为什么不在）
