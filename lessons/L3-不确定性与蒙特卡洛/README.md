# L3 · 不确定性与蒙特卡洛 —— 最坏最好会到哪？概率多大？

**问题**：别再要"一个数"。给定输入的不确定性，结果的**可能性分布**是什么样？
**模型肌肉**：随机模拟（蒙特卡洛）/ 输入相关性 / 分位数解读 / 收敛性
**标配图**：分位数扇带（P10–P90 路径）+ 结果分布图
**主权**：一起做（你定假设与口径）

## 先猜
1. 现金流模型里，哪些输入本身应该用"分布"而不是"点值"描述？
2. 两个输入变量（如售价与去化率）通常同向还是反向？为什么这重要？
3. 模拟 1000 次就够了吗？

## 最小数学
- 随机变量与分布：把"点"换成"范围 + 形状"
- 相关性怎么进模拟：同向变量要一起抽——让"坏"尽量同时发生（尾部会变肥）
- 分位数解读：P10 不是"最坏"，最坏在尾部之外；扇带讲的是"多数情况的区间"
- 收敛性：跑 100 / 1000 / 10000 次，看关键分位数是否稳定

## 动手
1. 拿 L2 的现金流模型，选 3–4 个输入变量，给每个定分布（三角 / 正态 / 历史分位法）
2. 设定相关性（先用简单分组相关系数），跑蒙特卡洛（先 1000 次）
3. 输出：结果分布 + P10 / P50 / P90 + 亏损概率（低于阈值的占比）
4. 学员亲手改：把相关系数从 0 调到 0.5，看"最坏情况"怎么变

## 验证
- 两版对照：独立假设 vs 相关假设，差异写清楚
- 埋雷：不固定种子 / 100 次就下结论 / 输入独立性拍脑袋（`docs/05` L3）

## 教给别人
一页纸《结果概率区间说明》：关键分位数 + 亏损概率 + 对输入的敏感说明
