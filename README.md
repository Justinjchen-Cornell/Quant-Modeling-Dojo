# 定量建模训练场 (Quant Modeling Dojo)

> **8 堂课 × 真实问题 × 可复现代码** —— 把数学建模的流程纪律（假设预检 → 建模 → 验证 → 表达）变成投资与重组工作里的定量判断力。
>
> 先猜后教 · 埋雷验证 · 教给别人 —— 判断力在你手里，算力交给 AI 教练。

## 这是什么

一个可长期运行的**定量建模训练系统**。不是竞赛课、不是编程课，而是一套训练协议：

- **每课回答一个真实工作问题**（指标可靠吗 / 扛得住多坏 / 谁在驱动 / 凭什么说它行……）
- **六步仪式**：抽查 → 先猜后教 → 最小数学 → 动手 → 验证（含埋雷）→ 教给别人
- **主权渐进移交**：L1–2 教练示范 → L3–5 一起做 → L6+ 你主刀、教练当"投委会质询"
- **产出三件套**：每课一张图 + 一页纸 + 一段能讲给别人的话

## 课程地图

| 课 | 要回答的问题 | 模型肌肉 | 标配图 |
|---|---|---|---|
| **L1** | 这个指标可靠吗？（GOR 45 审计） | 分布 / 分位 / 基准率 | 分布图 · 云雨图 |
| **L2** | 扛得住多坏的情况？（现金流压力测试） | 情景 vs 敏感性 | 龙卷风图 · 热图 |
| **L3** | 最坏最好会到哪？（不确定性定量） | 蒙特卡洛 | 分位数扇带 |
| **L4** | 谁在驱动结果？（归因） | 回归 / 相关≠因果 | 相关矩阵组合图 |
| **L5** | 凭什么说它行？（评估纪律） | 交叉验证 / 防数据泄露 | CV-ROC · 泰勒图 |
| **L6** | 有限资源怎么分？（配置） | 约束优化 | 有效前沿 · 权重图 |
| **L7** | 证据来了，改不改判断？ | 贝叶斯更新 | 决策树 · 后验图 |
| **L8** | 出师演练：全流程独立走一遍 | 六步全链条 | 技术路线图 + 一页纸 |

## 怎么用

### 1. 装教具（一次性）

```bash
# Claude Code 技能：建模流程 + 科研绘图
npx skills add jihe520/MathModelAgent
npx skills add jihe520/sci-box

# Python 依赖
pip install numpy pandas matplotlib scipy requests
```

细节见 `docs/04-教具安装.md`。

### 2. 开课

在 Claude Code 里说：

```
上建模课
```

教练会：读取进度 → 带你走六步 → 更新进度和学习记录 → `git push` 同步。

### 3. 每课之后

- 进度自动写回 `progress.md`
- 学习记录沉淀到 `records/`
- 所有图与脚本留档在对应课目录，随时复现

## 学习法（为什么这样设计）

- **检索练习**：每课开头先抽查上一课（你讲，教练听）；新概念先让你"猜"
- **间隔 + 交错**：8 课主题交错推进，复习分散在各课开头
- **难度是工具**：验证步永远比你以为的多一步（两版对照 + 埋雷）
- **教是最好的学**：每课产出以"能教给别人"为验收标准

## 出师标准

1. 拿一个全新问题，30 分钟内写出变量 / 假设 / 目标 / 约束的口径清单
2. 能识别并拒收带数据泄露、幸存者偏差或口径错误的分析
3. L8 全流程独立完成，守得住"投委会式质询"
